# Tools Used & Selection Rationale

This document explains the technical tools selected for each of the 7 agents in the **AI Presentation Designer Agent** project and the rationale behind their selection.

---

## 1. Orchestrator Agent
- **Tool / Framework**: `LangGraph` (`StateGraph` and conditional routing edges)
- **Why Chosen**: LangGraph provides explicit state management, cycle/feedback loop support (e.g. content feedback loop, refinement design loop), and strict state transitions between multi-agent nodes.

---

## 2. Content Agent
- **Tool**: Custom `Buzzword Linter` regex filter + LLM Directives
- **Why Chosen**: Standard LLMs tend to use marketing fluff (*unlock, revolutionize, seamless*). A deterministic post-processor filter combined with direct system prompts ensures plain, professional, human-sounding text.

---

## 3. Diagram Agent
- **Tool**: `Mermaid.js` syntax + `Kroki REST API` / `mermaid-cli` (`mmdc`)
- **Why Chosen**: Mermaid code can be easily generated by LLMs in plain text markdown format. Kroki renders this code cleanly into vector/PNG images without complex local setup overhead.

---

## 4. Image Agent
- **Tool**: `Unsplash REST API` & `Pexels REST API` + Fallback Visual Asset Generator (`Pillow`)
- **Why Chosen**: Unsplash and Pexels provide high-resolution, free stock photos. Querying with slide-specific keywords ensures contextually rich visual assets instead of generic placeholder imagery.

---

## 5. Design Agent
- **Tool**: `HTML5 / CSS3 Grid System` + `Pydantic Structured Slide JSON Schema`
- **Why Chosen**: Coded HTML layouts allow precise control over font hierarchy, color variables, grid placement, and widescreen 16:9 ratios before conversion to presentation elements.

---

## 6. Refinement Agent
- **Tool**: `Playwright` Headless Browser (`1920x1080` viewport rendering)
- **Why Chosen**: Rendering coded slides to PNG screenshots allows visual QA auditing against strict Design Standards (margins, text line limits, contrast, alignment).

---

## 7. Export Agent
- **Tool**: `python-pptx`
- **Why Chosen**: `python-pptx` programmatically creates native Microsoft PowerPoint `.pptx` elements (text boxes, shapes, paragraph font properties, pictures). Unlike flattening slides into static images, every element remains 100% separately selectable and editable in normal presentation software.
